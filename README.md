# Landing Page — Dr. Rodrigo Pires

Landing page de campanha do Dr. Rodrigo Pires, ortopedista e traumatologista em Brasília.

## Publicação

Todo push para `main` publica a página automaticamente na Vercel, no time Pulso. A página é servida a partir de `index.html` e os ativos ficam em `img/`.

## Pendências antes de Ads

Consulte `docs/checklist-entrega.md`. A página ainda exige a bridge de WhatsApp definitiva, política de privacidade aprovada, endereços completos e validação dos eventos no ambiente publicado.
